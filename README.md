# π-clock

Terminal clock that represents time as fractions of π.

```
╔══════════════════════════════════════╗
║         π-ЧАСЫ (электронные)         ║
╠══════════════════════════════════════╣
║                                      ║
║   Время: 03:30:00                     ║
║   π-время: (1/2:1/12)π = 7π/12         ║
║                                      ║
╚══════════════════════════════════════╝

╔══════════════════════════════════════════════╗
║            π-ЧАСЫ (круговые)                ║
╠══════════════════════════════════════════════╣
║  * часовая  + минутная                      ║
╠══════════════════════════════════════════════╣

                      [0]
       11π/6     ·····◎·····    π/6
             ·○··           ··○·
          ····                 ····
  5π/3   ··                       ··  π/3
        ○·                         ·○
       ·                             ·
      ··   * *                       ··

3π/2  ○               ⊙* * * * * *◆  [π/2]

    Текущее положение стрелки: 7π/12
```

## Математика

| Единица | Значение |
|---------|----------|
| 1 час   | π/6      |
| 1 минута | π/360   |
| 24 часа | 4π       |

Электронные часы: `(часы-π : минуты-π)π = сумма`

- 3:30 → `3 × π/6 = π/2`, `30 × π/360 = π/12`
- Сумма: `π/2 + π/12 = 7π/12`
- Вывод: `(1/2:1/12)π = 7π/12`

Дроби всегда сокращаются через НОД.

## Запуск

```bash
cargo run
```

## Требования

- Rust 2024 edition
- Без внешних зависимостей (только `std`)
- macOS / Linux (используется `localtime_r` из libc для локального времени)

## Структура

```
src/
├── main.rs       — точка входа, получение системного времени
├── fraction.rs   — дробная арифметика (НОД, сложение, Display)
├── clock.rs      — преобразование времени в π-дроби
└── display.rs    — ASCII-циферблат
```
